# ERP Project

This project started as an HR platform and has grown into a full ERP system.  
It currently includes:

- **HR Module**: Employee management, leave tracking
- **Administration Module**: Marriage registration (ordinary 21 days, express 14 days)
- **Database**: hr_platform.db
- **Dependencies**: Listed in requirements.txt

## How to Run
1. Create a virtual environment:
   python3 -m venv venv
   source venv/bin/activate

2. Install dependencies:
   pip install -r requirements.txt

3. Run the application:
   python3 SRC/app.py
